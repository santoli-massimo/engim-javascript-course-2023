# JavaScript Course — Engim Torino, 2023 edition

Teaching material from the JavaScript / web development course I taught at
Engim Torino (vocational training school) — 2023 edition of a course series
I've been running since 2016 (see my other engim-* repositories).

## Structure

- `00Docente/` — instructor material: 11 progressive lessons
  (operators → functions → DOM → events → final test). In Italian.
- `studenti/` — a small anonymized selection of real student coursework
  (`studente-NN`). **Student code was written by the students, not by me** —
  kept as a record of how the course worked in practice.

Archived record of a completed course.
